# Task 4 report tables

All values are generated by `python3 analysis/collect.py` from explicitly
selected audited exports. Each row retains `job_id`, `group`, the selected
`repeat`, numerical validation and min/median/max/CV statistics. Source samples
are in `../analysis_samples.csv`; input hashes and exclusions are in
`../analysis_manifest.json`.

| Table | Rows | Purpose |
| --- | ---: | --- |
| `serial_scaling.csv` | 11 | Serial size sweep, iteration growth and discretization error |
| `strong_endpoints.csv` | 16 | Both dimensions/decompositions at 1,64,256,288 cores |
| `weak_scaling.csv` | 10 | Five points in each dimension, both through 256 physical cores |
| `variant_comparison.csv` | 16 | Four halo/CG choices at 64/256 cores, both dimensions |
| `hybrid_comparison.csv` | 12 | Six MPI/OpenMP splits at fixed 288 cores, both dimensions |

`speedup`/`efficiency` apply to strong scaling with each decomposition's own
one-rank MPI reference. `matched_mpi_ratio` is a same-resource comparison for
variants/hybrid. `weak_solve_ratio` includes convergence growth;
`weak_iteration_ratio` normalises by iteration count. Ratio `_median`, `_low`
and `_high` columns are defined in [the analysis guide](../../analysis/README.md).
Blank entries are intentionally inapplicable. Independent phase maxima are
not additive and their sum is not a communication fraction.
